Lab0. Ответы на вопросы о Git



1. Ветка — это лёгкая метка на определённый коммит в истории Git, а не физическая копия файлов. Она позволяет вести параллельную разработку, не дублируя весь проект на диске. При переключении между ветками Git сам подменяет содержимое рабочей папки в соответствии с нужным коммитом.



2\. История сохранится, потому что все коммиты, ветки и настройки лежат внутри папки .git. Если затем восстановить файлы из этого .git (например, командой git checkout), получится та же самая версия проекта. Без .git остаётся просто набор файлов, и Git уже не сможет восстановить историю



3.Pull Request позволяет проверить изменения до их попадания в основную ветку: код-ревью, автотесты, обсуждение. Это особенно важно в командной работе, чтобы случайно не сломать стабильную версию main. Кроме того, PR оставляет след в истории — видно, кто, когда и зачем внёс изменения.
